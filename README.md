# LUMORA

### Modern Technology Landing Page

LUMORA is a modern, responsive technology landing page built with vanilla HTML, CSS, and JavaScript.

The project focuses on clean UI, responsive design, smooth interactions, and a minimal futuristic aesthetic.

---

## ✨ Features

* Responsive design
* Dark / Light mode
* Mobile navigation menu
* Smooth scrolling
* Interactive contact form
* Form validation
* CSS animations
* Modern responsive layout
* Semantic HTML structure

---

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

### 1. Clone the repository

```bash

```

### 2. Open the project

Open the project folder in your code editor.

### 3. Run the website

Open `index.html` in your browser.

No additional dependencies are required.
